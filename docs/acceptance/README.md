1. [`videos/power-split-planets.mp4`](videos/power-split-planets.mp4) — isolated power-split view with carrier orbit, planet self-spin, sun/MG1, ring/output, signed markers, and live power paths.
2. [`videos/mg2-reduction.mp4`](videos/mg2-reduction.mp4) — isolated fixed-carrier MG2 reduction with the sun, planet self-spin, counter-rotating ring, and final drive.
3. [`videos/direction-reversal.mp4`](videos/direction-reversal.mp4) — D torque while initially rolling backward, transitioning from regeneration through zero speed to EV propulsion.
4. [`videos/engine-start.mp4`](videos/engine-start.mp4) — battery/inverter/MG1 cranking flow and engine rotation during the feasible-work start transient.
5. [`videos/drive-and-charge.mp4`](videos/drive-and-charge.mp4) — live vehicle motion, engine power, MG1 generation, and battery charging.
6. [`videos/regeneration.mp4`](videos/regeneration.mp4) — wheel-to-MG2-to-inverter-to-battery power flow during braking.
